# CM4DI Profile Concept Reference v2

Status: **Wave-6 governed concepts; source-citation hardening active under Issues #60, #72 and #77**.

These 68 concepts are extension/profile concepts. Their definitions remain neutral CM4DI definitions. Vendor, protocol and jurisdiction-specific constructs are evidence/mapping targets, not automatic equivalents.

## Evidence gaps explicitly retained

- Agent Identity concepts require a stronger current academic/industry source wave before final formal-axiom commitment.
- Device Identity needs broader device-platform/MDM evidence beyond authentication and directory examples.
- `HolderService`, government institutional roles and some trust-governance constructs require source-by-source EU/global framework reconciliation in #62/#63.
- Profile concepts are not promoted to Core because they have many product/standard instances.

Issue #77 will convert this human-readable reference into a machine-readable definition/provenance registry with Persian/English labels, exact DDD/Bounded Context ownership, CQ links and evidence completeness status.
