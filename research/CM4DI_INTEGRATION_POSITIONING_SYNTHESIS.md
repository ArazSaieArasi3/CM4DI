# CM4DI Integration Positioning Synthesis — Working Baseline

Owner: #135 / #141  
Status: **Provisional; publication claims remain blocked on #60, #66, #136 and #137.**

## Current positioning
CM4DI is being evaluated as an integrated, UFO-grounded, cross-paradigm digital-identity reference ontology. The intended contribution is not to replace mature adjacent ontologies or to claim that no prior identity ontology exists. Instead, CM4DI seeks to provide a coherent semantic layer connecting identity representation, evidence and establishment, credential lifecycle/exchange, authentication, authorization, administration, federation, workload/device/agent identity, trust governance and government identity.

## Evidence pattern emerging
Current standards and operational-system evidence repeatedly supports distinctions that are commonly collapsed in implementation vocabularies:
- IdentitySubject != DigitalIdentity != Account != UserProfile != Identifier.
- Federation != Provisioning.
- AuthenticationResult != Session.
- Permission != PermissionBundle != AccessGrant.
- Application != ApplicationRegistration != ServicePrincipal != Workload.
- co-reference/account linking != semantic identity equality.
- technical TrustDomain != institutional TrustFramework.
- Holder != CredentialSubject; Device != Authenticator; AgentIdentity != AIAgent.

## Neighbor-ontology strategy
Generic foundational, provenance, organization, privacy, trust and policy semantics should be reused/aligned/bridged where mature external ontologies already own them. CM4DI should own the digital-identity-specific integration semantics and explicit bridges among these neighboring areas.

## Publication test
The journal contribution is defensible only if the final evidence shows:
1. broad but declared cross-paradigm coverage;
2. source-complete standards/EU/framework alignment;
3. explicit direct-competitor delta;
4. conservative neighbor reuse decisions;
5. executable OWL/SHACL/CQ/reasoning;
6. reproducible evaluation against implementations and datasets.

No claim of 'first digital identity ontology', 'first UFO-grounded identity ontology', or unrestricted completeness is permitted.
